# Py-Recursividad
Este repositorio contiene una colección de programas en Python que implementan algoritmos recursivos para operar sobre listas, polinomios y otras estructuras de datos. Se incluyen ejemplos de manipulación de listas, suma y resta de polinomios, y funciones recursivas aplicadas a problemas matemáticos y computacionales.

## Archivos

1. **Buscar elemento en su posición**:
   - Archivo: `buscar_elemento.py`
   - Descripción: Este script permite leer una lista de números y buscar un elemento que esté en su posición correspondiente. Si el elemento se encuentra en su posición, devuelve el índice; de lo contrario, devuelve -1.

2. **Imprimir polinomio**:
   - Archivo: `imprimir_polinomio.py`
   - Descripción: Este script permite leer un polinomio representado por sus coeficientes y lo imprime en su forma matemática. Maneja adecuadamente los signos y evita imprimir términos innecesarios.

3. **Suma y resta de polinomios**:
   - Archivo: `suma_resta_polinomios.py`
   - Descripción: Este script permite sumar y restar dos polinomios ingresados por el usuario, mostrando los resultados en su forma matemática.

4. **Multiplicación de polinomios (Karatsuba)**:
   - Archivo: `multiplicacion_karatsuba.py`
   - Descripción: Implementa el algoritmo de Karatsuba para multiplicar dos polinomios de manera eficiente. Los resultados se imprimen en su forma matemática.
